SCOPE & LIMITS

A learning environment, with boundaries.

The example changes a message inside a sandboxed iframe. There are no accounts, sessions, stored comments, or external data transfers.

Use the documented inputs. Arbitrary JavaScript can still freeze a frame or tab. The demo deliberately allows inline script; do not copy its CSP into production.

See the repository's docs/REPORT.md for the technical write-up and docs/TESTING.md for evidence and test coverage.
